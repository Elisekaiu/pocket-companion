# Pocket Companion · 口袋里的小伙伴

一份设计笔记：怎么做一只住在你和 AI 伴侣之间的像素小宠物。它既在你的 App 里，也在 AI 的工具里。

> English version: [`english` branch](https://github.com/Elisekaiu/pocket-companion/tree/english)

这不是一个拿来就能用的 App，而是一个每天都在用的小宠物背后的做法：原则、后端设计、换装系统、文字系统、像素渲染，还有一路踩过的坑。角色、美术、喜好和台词属于一段私人的关系，所以没有放进来。**系统可以共用，小伙伴应该是你自己的。**

## 它和普通的电子宠物有什么不一样

- **只对“真的在”有反应。** 它知道你来过，是因为你真的打开了 App、发了消息、读了书、一起看了片。不会为了显得热闹而假装。
- **活在真实时间里。** 饿、困、想你，都是按真实时钟从事件日志里推算出来的。不管什么时候打开，它都处在对的状态，不需要后台定时器。
- **随机，但永不重抽。** 每一个“随机”（回复、明信片、事件）都是由它的 id 算出的固定哈希。刷新不会改变发生过的事，也没人能刷出更好的结果。
- **一只宠物，两个照顾者。** 你的 App 和你的 AI 伴侣通过同一份后端接口（和 MCP）读写**同一份**状态。AI 可以喂它、送它东西、读它的小本子，但只能以自己的身份行动，不能冒充你。
- **一起做的事都算数。** 一起看片、一起读同一本书（借助 plus-one 和 coread 这样的工具，见致谢），它就会窝在沙发上或台灯下陪你们。
- **旅行是一个超大的组合。** 它按真实时间出门旅行，带回来的明信片由很多小池子拼成：地点、天气、景点、遇见了谁、吃了什么、小意外、P.S.，所以每次旅行都不一样。地点和喜好是很私人的东西，请换成你们自己的。
- **温柔，有边界。** 数值有下限，亲密度每天有上限，重复的动作收益递减；它不会死，也不会惩罚你。你离开太久，它会想你，但不会受苦。

## 小家伙会做的事（和它会说的话）

它有很多很多反应，下面只是一小部分 🥹

**📓 小本子：写什么，它就回应什么**

| 你写 | 它 |
|---|---|
| 我爱你 | 脸红了 ♥「再说一次好不好？我想再听一次。」 |
| 我爱你（又一次） | 「贴贴！（扑过去）」：同一句话，每次回应都不一样 |
| 我讨厌你！ | 有点受伤 ; ;「那我去角落坐一会儿……你叫我，我马上就过来。」 |
| 对不起嘛，晚安 | 原谅你啦 ^ ^「没关系没关系！我早就不难过了。」+「晚安哦。」 |
| 今天好累，加班到很晚 | 想让你歇一歇 …「先闭眼休息五分钟吧，我帮你数羊。」 |
| 头好痛，感冒了 | 好担心你 …「要多喝热水，早点睡。我在旁边帮你看着时间。」 |
| 今天考试过了！ | 为你骄傲 !!「要不要庆祝一下？我请你吃小蛋糕。」 |
| 没考过…… | 想抱抱你 ♥「我不太会说话，可是我可以一直在这里。」 |
| 你好可爱 | 被夸了 !!「（原地转了三圈）」 |
| 下雨了 | 看着窗外的雨 …「打雷的时候我会捂住耳朵，你也可以捂住我的。」 |

二十多种情绪，好的坏的都有；懂“不”字（不爱你 ≠ 爱你），也懂混合的心情。

**✈️ 旅行：每次都不一样**
- 它会带回由很多小块拼成的明信片：“雾好浓，路灯像一颗颗小月亮。在夜晚的广场，我想起了你。”
- 有时候会有小意外：“风把他的帽子吹进了河里，一只鸭子帮他捡了回来。”“他坐错了车，多看了半座城。”
- 当地的偶遇：船夫叔叔一边划船一边唱歌给他听；一头驯鹿用鼻子碰了碰他的手。
- 有时候多带回一件纪念品；长途旅行还会再寄一张明信片。
- 玩得开不开心，取决于目的地合不合它的喜好，还有它带了什么（下雨天带了伞：“带的东西刚好用上”）。

**🌙 你不在的时候**
- 它会从“偶尔想你”慢慢变成“在等你”“很想你”“等了好久”。
- 你回来时，是**一次**真正的重逢，有时它还会把等你时画的画送给你：“画了你”“画了我们的小窝”。
- 它会捡到一朵小花，夹在书里留给你：“他捡到的，第一个想到你。”
- 它会做奇怪的梦，醒来记下来。
- 太久没人照顾时，它会自己吃点零食、洗一洗（历史里会老老实实写着“他自己照顾了自己”）。

**🎁 礼物、心愿和小事件**
- 送礼物时的反应取决于它稳定的喜好和当下的状态（困的时候、冷的时候、想你的时候）。重复送收益会变少，但它永远不会讨厌。
- 它有时会许一个小心愿，你刚好送对了，它会特别开心。
- 小事件会突然出现：“他在抽屉里找到了什么”“他想问你一个小问题”。你的选择只算一次，不会重抽。

**🙅 拒绝也很可爱**
- 刚吃饱再喂：会被拒绝，还会说明原因。
- 睡着时想让它玩：“他睡着了”。
- 今天已经庆祝过一次了？“今天已经庆祝过了”。

**🛋️ 一起的时光**
- 一起看片：它裹着毯子盯着屏幕，暂停时会四处张望，看完伸个懒腰。
- 一起读书：只有真的在读才算；你和 AI 读同一本书时，它是“一起读”的样子。
- 特别的日子按一下“庆祝”，它会开心六个小时。

**👕 换装和成长**
- 衣服、帽子、围巾、翅膀、尾巴饰品，可以先在试衣间预览再确认；睡觉时衣服会叠好放在旁边。
- 可以换不同的外壳和房间背景，背景也可以跟着时间和它在做的事自动变。
- 它长大时，看得出来：额头的标记会变，身边会有小星星。
- 闲着的时候它会在房间里走来走去、转身、小跳一下。

**🤝 AI 伴侣也在**
- AI 伴侣可以喂它、读它的小本子、送它去旅行，还能送它一件新衣服并附上一句话。
- 它做的每件事都以自己的名义记录，不会冒充你。

## 怎么用这些笔记

1. 先设计你的小伙伴（`art/ART-PROMPT-KIT.md` 第 0 节）：非人类、缩小后还认得出、属于你。
2. 读 `01-principles.md`，决定要保留哪些原则。它们会影响后面的一切。
3. 后端用“事件日志 + 纯函数”来做（`02-backend.md`），把内容（喜好、地点、台词）放在数据里，不要写死在代码里。
4. 让 AI 伴侣通过同一组操作接入（`03-mcp-for-companions.md`）。
5. 核心循环顺了，再加换装、文字系统和渲染细节。
